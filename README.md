# 渠道时效管理后台

中航环球渠道时效系统的独立管理端原型，使用 React + TypeScript + Ant Design + Tailwind CSS，服务端使用 Fastify 与 Node.js 内置 SQLite。

## 已包含

- 柜子生命周期：装柜、开船、到港、卸船、可提柜、提柜、拆柜
- 装载仓库与多批送仓，维护计划/实际送仓日期、件数与体积
- 多条查验记录，支持查验中、放行及查验说明
- 航线管理：公司渠道、具体航线、船公司、起运港、目的港与参考时效
- 亚马逊仓库管理：代码、地区、地址、启用状态
- 前台展示管理：柜子、航线、仓库、送仓批次分级开关与本地前台预览
- 操作日志：新增、修改、删除及展示开关的前后值对比
- 新记录默认不展示、乐观锁版本校验、日期顺序校验、引用保护

当前是独立本地演示环境。数据保存在 `.data/admin.sqlite`，默认启动时写入合成演示数据；本地展示开关不会改变线上时效前台，也没有接入生产数据库和登录系统。

## 开发

```sh
npm install
npm run dev:api   # 127.0.0.1:3102
npm run dev       # 127.0.0.1:4180
```

打开 <http://127.0.0.1:4180>。

## 验证

```sh
npm run typecheck
npm test
npm run build
```

构建后可执行 `npm start`，服务端会优先使用 `dist/client` 提供静态前端，API 仍在 3102 端口。生产适配、身份认证、数据库迁移以及与线上前台的展示字段联动属于下一阶段。
